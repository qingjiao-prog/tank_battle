# 坦克大战 (Tank Battle)

一个用纯 HTML + Canvas + JavaScript 编写的经典坦克大战小游戏，单文件、零依赖，浏览器打开即玩。

## 玩法

- 控制你的坦克，消灭场上所有敌方坦克。
- **守住基地（底部的旗帜）**——基地被击中游戏立刻结束。
- 摧毁砖墙可以开辟道路，钢板墙坚固无比（顶级火力可击穿）。
- 消灭闪烁的红色「奖励坦克」会掉落道具。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击（可按住连发） |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |
| Enter | 开始 / 重新开始 |

## 道具

- 🛡 护盾 —— 一段时间内无敌
- ➕ 生命 —— 增加一条命
- 💣 炸弹 —— 消灭场上所有敌人
- ★ 升级 —— 提升火力（可发射两发、射速与威力提升、可击穿钢板）
- ❄ 冰冻 —— 冻结场上所有敌人

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 技术要点

- 网格地图（砖墙 / 钢板 / 水 / 草丛）
- 坦克与子弹的 AABB 碰撞检测、子弹分步移动防穿透
- 敌人 AI：随机转向 + 周期性开火
- Web Audio API 音效、粒子爆炸特效
- 多关卡（地图循环、敌人逐步增强）
